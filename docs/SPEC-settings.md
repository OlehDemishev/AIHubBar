# Настройки: модули, места показа, строка меню — техзадание

Согласовано с Олегом 2026-11-02: вариант **A** (боковая панель по разделам, у каждого модуля своя страница), страница
«Модули» плитками из варианта **B**, страница «Панель» — конструктор из варианта **C**, редактор строки меню с
разделителями. Макеты — в разговоре 2026-11-02 («Настройки — каша»).

Продолжает `docs/SPEC-profiles.md` (модули и профили). Там, где этот файл говорит иначе, верен этот.

## 1. Три уровня настройки модуля

1. **Модуль** — один главный выключатель. Есть у каждого модуля, и у встроенных («Лимиты AI», «Сессии агентов»,
   «Ближайшее», «Проекты», «Отчёты») тоже. Выключенный модуль:
   - не работает в фоне (лимиты не опрашиваются, «Ресурсы» не меряются, «Раскладка» не слушает клавиатуру);
   - не виден в панели, его элементы не рисуются в строке меню, его уведомления не приходят;
   - остаётся в профилях на своём месте: включили снова — всё как было.
   Так можно оставить только AI или только «Раскладку».
2. **Функции** — строки модуля со значком: тумблеры и выбор.
3. **Где показывать** — чипы над функциями: «Панель», «Строка меню», «Остров», «Уведомления», «Telegram». У модуля
   только те места, что у него бывают. Чип — короткий путь к уже существующим настройкам, отдельного хранения нет:
   - «Панель» — модуль показан в текущем профиле;
   - «Строка меню» — включён хоть один элемент модуля в строке меню текущего профиля (включить — включаются основные);
   - «Остров» — ушко острова показывает модуль («Лимиты», «Сессии»), когда «Остров у чёлки» включён;
   - «Уведомления» — частота уведомлений модуля не «не присылать»;
   - «Telegram» — дубли модуля в Telegram.

Хранение: `state.json` профилей получает `off` — модули, выключенные главным выключателем. Модуль работает, когда он
установлен и не в `off`. Файлы без `off` читаются как прежде: всё установленное включено.

## 2. Окно настроек

Боковая панель, как в Системных настройках, с поиском. Разделы:

- без заголовка: «Основные», «Профили», «Внешний вид», «Модули» (плитки), «Панель» (конструктор), «Строка меню»;
- **AI**: «Лимиты AI», «Сессии агентов»;
- **Сервисы AI**: Claude Code, Codex, Gemini, Copilot, Cursor, другие — как сейчас;
- **Работа**: «Ближайшее», «Проекты», «Отчёты», «Быстрые команды», «Заметки», «История буфера»;
- **Mac**: «Ресурсы Mac», «Не спать», «Переключатели», «Раскладка», «Остров у чёлки».

Цвет плиток значков — по разделу (AI фиолетовый, Работа зелёный, Mac оранжевый, общие серые). Выключенный модуль в
боковой панели бледный. «Раскладка» видна только с «Бета-версиями».

Страница модуля сверху вниз: крупный значок, название, что делает, главный выключатель; чипы мест; функции. Текст
крупнее прежнего (14 pt вместо 13), у основных строк значки.

## 3. «Модули» — плитки

Наборы сверху: «Только AI», «Только раскладка», «Утилиты Mac», «Всё». Набор включает свои модули и выключает
остальные; модули, которых профиль не может показать (нет календаря — нет «Ближайшего»), не трогаются. Ниже плитки по
разделам: значок, название, одна строка, выключатель. Клик по плитке — страница модуля.

## 4. «Панель» — конструктор

Модули текущего профиля сверху вниз: перетаскивание, тумблер «показывать», выбор показателей там, где он есть
(«Ресурсы», «Быстрые команды», «Переключатели», «Не спать»). Рядом схема панели в том же порядке. Модули, выключенные
главным выключателем, в списке не показываются.

## 5. Строка меню

- Живая строка сверху: элементы перетаскиваются, клик по элементу — его настройки (вид числа, порог, модель…).
- Ниже элементы по модулям; элементы выключенных модулей не предлагаются.
- **Разделители**: пробел, широкий пробел, точка «·», черта «|», тонкая линия, косая «/», стрелка «›», «новая
  группа». Ставятся сколько угодно раз, между любыми элементами.
  - Хранение: `dividers` — список «после какого элемента, какой разделитель»; несколько после одного элемента — по
    порядку. Старые версии это поле не знают и рисуют как раньше.
  - Разделители рисуются только между двумя видимыми элементами: если элемент сейчас пуст (никто не ждёт ответа),
    его разделители не висят по краям.
  - Где своих разделителей нет — прежнее правило: общий разделитель между числами, маленький зазор у значков.
- **Вид «Капсулы по группам»**: элементы между «новыми группами» рисуются на общей скруглённой подложке.

## 5a. Доработки (2026-11-02, вторая волна)

- Порядок меняется и без мыши: ⌃/⌄ у блоков «Панели», «Левее / Правее / Убрать» у фишек строки меню — кнопками в
  инспекторе, контекстным меню и действиями VoiceOver.
- Блоки панели правятся только в «Панели»: там выбор профиля и «Добавить модуль»; в «Профилях» — состав панели строкой и
  кнопка «Изменить в «Панели»…».
- Частота уведомлений — на странице модуля («Как часто уведомлять»), не списком в «Основных». Результаты команд —
  у «Отчётов» и «Быстрых команд».
- Значки у всех строк настроек. Длинные пояснения показывают первое предложение и «Подробнее».
- Встроенный модуль, которого нет в профиле: на плитке и странице — кнопка «Включить в профиле» (календарь, команды
  `_daily-report`) или «Открыть профиль» (проектам нужна папка).
- «Фоновые задачи» — на странице «Сессии агентов», рядом с её чипом Telegram (итоги фоновых задач).
- «Панель сейчас» — мини-панель с живыми данными блоков, не сама панель: та управляет своим окном и обновляется при
  открытии.
- «Сервисы AI» в боковой панели свёрнуты, пока не нужны. Окно настроек растягивается (минимум 820 × 560).

## 6. Этапы

1. Модель: главный выключатель у всех модулей, `off`, отключение фона, уведомлений и строки меню. Тесты.
2. Окно: боковая панель по разделам, страницы модулей, чипы мест, крупнее текст.
3. «Модули» плитками с наборами, «Панель» — конструктор.
4. Строка меню: разделители, капсулы, новый редактор. Тесты композитора.

## 7. Чего не делать

- Не переносить настройки в новые ключи: чипы и страницы читают и пишут то, что уже есть.
- Не ломать экспорт `.claudepult` и чтение старых файлов.
- Не трогать профили Олега: после обновления всё выглядит и работает как раньше, пока он сам что-то не выключит.
