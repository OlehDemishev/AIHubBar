# ClaudePult: профили и модули — техзадание

Продолжение `docs/SPEC-modes.md`. Согласовано с Олегом 2026-10-30: **вариант C**.
- Модули ставятся один раз из каталога, вместе с разрешениями и фоновой работой.
- Профиль решает, какие из установленных модулей показывать, в каком порядке и с какими своими настройками.
- По умолчанию всё пусто; профиль создаётся помощником или в Настройках.

Пункты с пометкой **(предложено)** — решения, которые Олег ещё не подтверждал; их можно поменять до начала этапа, к которому они относятся.

Идеи частично взяты у Vorssaint (бесплатное приложение для строки меню, GPL-3.0). Берём только идеи: код Vorssaint не копируем, иначе ClaudePult тоже стал бы GPL.

## 1. Понятия

- **Модуль** — одна возможность ClaudePult: «Лимиты AI», «Проекты», «Ресурсы Mac», «Не спать» и т. д. (§3).
  - Сначала модуль **ставится** из каталога: Настройки → «Модули». Только после этого он работает в фоне, спрашивает нужные разрешения и появляется в профилях.
  - Неустановленный модуль ничего не делает и ничего не спрашивает. Если модуль снять, его настройки сохраняются и вернутся при повторной установке.
- **Общие настройки модуля** — то, что не зависит от профиля: пороги уведомлений, правила «Не спать», ключи и т. п. Живут в каталоге.
- **Профиль** — название, значок и упорядоченный список модулей: какие показывать в панели, в каком порядке, свёрнут ли блок. К этому добавляются **настройки модулей в профиле**: например, у «Проектов» это папка, карточка, этапы, команды и сервис AI. Сюда переезжают нынешние «кубики» режима.
- **Режим → профиль (предложено).** В интерфейсе слово «режим» заменяется на «профиль»: так понятнее людям, и так сказал Олег. В коде и файлах тип `Mode` переименовывается постепенно, файлы старого формата читаются всегда.
- **Шаблон профиля** — готовый набор модулей с настройками: «Разработчик с Claude», «Видео», «Тексты», «Ресёрч», «Соцсети», «Утилиты Mac», «С нуля».
- **Помощник** — пошаговое создание профиля (§5).

## 2. Пустой старт

- После установки ни одного профиля нет. В строке меню только ✦.
- Панель по клику показывает «Создайте профиль»: кнопки «Помощник…» и «Импортировать файл…», а ниже список готовности (сервис AI, hooks, уведомления, автозапуск — уже есть).
- Первый запуск сам открывает помощника, как сейчас.
- Пока профиля нет, ничего не работает в фоне: модули ставятся только вместе с первым профилем.

## 4. Новые модули

### 4.1 Ресурсы Mac
- **Процессор:** `host_processor_info`, общий % и по ядрам. **Память:** `host_statistics64` и давление памяти. **Диск:** свободное место на томах — сюда переезжает нынешний показатель «Свободно … ГБ». **Сеть:** байты по интерфейсам через `getifaddrs`, скорость вниз и вверх. **Батарея:** `IOPowerSources` — заряд, время, здоровье. **Графика:** `IOAccelerator` PerformanceStatistics, если macOS отдаёт. Температуры и вентиляторы — не в первой волне.
- Частота: каждые 2 с, пока панель открыта; в фоне — раз в 30 с, только для уведомлений и строки меню.
- «Прожорливые»: топ-5 процессов по процессору за последнюю минуту, клик — «Мониторинг системы».
- Уведомления: процессор выше 90 % дольше 5 мин, давление памяти «критическое», места меньше порога, заряд меньше 15 % без питания. Каждое — раз в событие.

### 4.2 Не спать
- Через `IOPMAssertionCreateWithName`: не давать системе засыпать; по выбору — и экрану. Ничего не меняется в системных настройках, после выключения всё как было.
- Правила (любое сработавшее держит Mac):
  - вручную: на 15 мин, 1 ч, 2 ч, до выключения;
  - пока подключено питание;
  - пока подключён внешний монитор;
  - **пока работает Claude:** есть работающая сессия или фоновая задача (из модуля «Сессии агентов»). Это наша фишка, **(предложено)** включено по умолчанию в шаблоне «Разработчик с Claude»;
  - пока запущены выбранные приложения.
- В панели: переключатель, «ещё 47 мин» или «держит: работает Claude». В строке меню: ☕, когда держит.

### 4.3 Быстрые команды
- Виды:
  - **скрипт** — команда shell. Запускается в фоне, итог приходит уведомлением, а по выбору команда открывается в Терминале;
  - **ярлык** — ярлык из приложения «Команды» macOS, через `shortcuts run <имя>`;
  - **открыть** — ссылку, файл, папку или приложение.
- У каждой команды: название, значок, «спрашивать перед запуском» и необязательное сочетание клавиш (вторая волна).
- Библиотека общая; профиль выбирает, какие команды показывать и в каком порядке.
- Нынешние команды `_daily-report` не трогаем, они остаются модулем «Отчёты».

### 4.4 Быстрые переключатели
- Тёмная тема — System Events (Автоматизация).
- Скрыть значки на рабочем столе — `defaults write com.apple.finder CreateDesktop` и перезапуск Finder.
- Заблокировать экран.
- Погасить экран — `pmset displaysleepnow`.
- Извлечь внешние диски.
- Очистить корзину — Finder (Автоматизация), с подтверждением.
- Всё это — действия по клику самого человека. ClaudePult ничего не переключает сам.

## 5. Помощник

Шаги (новые выделены):
1. Добро пожаловать и готовность — уже есть.
2. Перенести настройки? — уже есть.
3. **Чем вы занимаетесь?** — шаблоны профиля, включая новый «Утилиты Mac» (без проектов: Ресурсы, Не спать, Быстрые команды, Переключатели) и «С нуля».
4. **Модули** — галочки по каталогу. Шаблон отмечает свои, разрешения не спрашиваются до первого использования.
5. Настройки выбранных модулей. Для «Проектов» это нынешние шаги: папка, этапы, метрики, календарь, сервис, команды, права. Для «Не спать» — правила. Для «Быстрых команд» — пара готовых команд на выбор.
6. Строка меню — уже есть, но элементы предлагаются только от выбранных модулей.
7. Название и значок — уже есть.

Справа — живой предпросмотр панели профиля, как сейчас.

## 6. Настройки

Вкладки:
- **Основные** — как сейчас.
- **Профили** — бывшие «Режимы»:
  - список профилей;
  - справа — модули профиля (порядок, показывать, свёрнут) и их настройки в профиле;
  - «Добавить модуль в профиль» показывает только установленные.
- **Модули** — каталог: установлен или нет, общие настройки, какие разрешения нужны и выданы ли.
- **Внешний вид**.
- **Строка меню** — для выбранного профиля.
- **Сервисы AI**.
- **Claude Code** — путь, hooks и фоновые задачи. Лимиты переезжают в «Модули → Лимиты AI».

**(предложено)** Строка меню — у каждого профиля своя: при переключении профиля меняется и она. Набор «как в профиле по умолчанию» — для тех, кому это не нужно.

## 7. Переезд со старых режимов

- Каждый режим становится профилем, без изменений в поведении. Модули идут в нынешнем порядке панели:
  - «Лимиты» и «Сессии» — если не скрыты;
  - «Ближайшее» — если в режиме включён календарь;
  - «Проекты» — со всеми кубиками режима;
  - «Отчёты» — если «Общие команды» = `_daily-report`.
- Ставятся только модули, которые используются хоть в одном профиле.
- Глобальные «скрытые блоки» применяются к каждому профилю. Нынешняя строка меню копируется в каждый профиль. Свёрнутые блоки сохраняются.
- Режим Олега «Разработчик — Олег» выглядит и работает как сейчас.
- Файл `.claudepult`: версия формата 2 (модули, профили); файлы версии 1 читаются и переводятся.

## 8. Чего не делать

- Не спрашивать разрешения заранее: только при установке модуля и первом действии, которому оно нужно.
- Переключение профиля не выключает фоновую работу установленных модулей: уведомления о лимитах, сессии, «Не спать» продолжают работать. Профиль меняет только то, что видно.
- Не копировать код GPL-проектов.
- Не ломать сценарий Олега (SPEC-modes §8).
- Без телеметрии и без отправки данных куда-либо, кроме выбранного сервиса AI.
