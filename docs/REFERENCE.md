> Formerly **ClaudePult** (renamed 2026-10-30; the GitHub repository is now `OlehDemishev/AIHubBar`). The Xcode project, the bundle id `com.demishev.claudepult` and the data folders (`~/Library/Application Support/ClaudePult`, `~/Library/Logs/ClaudePult`) keep the old name, so settings, macOS permissions and Keychain items carry over. ## What it does

Click ✦ in the menu bar. Next to it, by default: the subscription usage (5-hour session and week % — green < 50 %, orange 50–80 %, red > 80 %), a red dot when a project's health is red and ✋ with the number of Claude sessions waiting for an answer. What the menu bar shows is built in Settings → “Menu Bar” (presets, elements and their order, gauge style, separator, text size, colour; live preview).

**Limits** (top of the panel) — the 5-hour session with a countdown to the reset and a forecast from the last 30 minutes (“lasts until ~16:40” / “will last until the reset”), the week, per-model weeks, extra usage if enabled; “Usage by project” estimates each project's share and the heaviest session for the session / today / week from Claude Code's transcripts. Notifications once per window at 50/80/95 % (configurable) and when a limit is restored, optionally to Telegram. A background run while the session is above 90 % asks: start now or after the reset. Data from the same endpoint Claude Code uses (OAuth token read from the Keychain item “Claude Code-credentials”, never stored); current values are written to `~/Library/Application Support/ClaudePult/usage.json` (`five_hour`, `seven_day`, `updated`) for report.py and the bot.

**Sessions** (top of the panel, from Claude Code hooks) — every session on this Mac: Terminal, Claude desktop app, background runs. Project, worktree, task, duration, state (working / background / waiting / done / error / ended). Waiting sessions are highlighted and notify once. “Show” brings the session's Terminal tab forward (desktop-app sessions open that session in Claude, others the folder); background runs have “Log” and “Stop”.

**Projects** — from `~/Projects/_daily-report/report.py --json`: health, branch, uncommitted files, open PRs coloured by CI, last activity. A project expands into:

- **Claude**: “Next step” (first Next item), “Custom task…”, “Finish” — prompts from spec §2.4. Each asks **Terminal** (new Terminal window with `claude "<prompt>"`) or **Background** (`claude -p`, see below), or uses the default from Settings (“Remember”). If Claude already works in the project folder, the new task starts in a worktree `.claude/worktrees/cb-<slug>` on branch `claude/<slug>` from `origin/main`; “Finish” asks before a second session in the same folder.
- “Terminal / Finder / GitHub”.
- The STATUS.md header (Stage / Now / Next / Needs Oleh), attention items, open PRs.
- Worktrees with a delete button (only when clean and pushed or merged).

Data refreshes at launch, on panel open when older than 60 s, every 5 min (`--no-fetch`), every 30 min with `git fetch`, and with ⌘R.

**Commands** — through the `_daily-report` tools, with a spinner, a result line and a notification: “Report now” (AI report for 24 h to Telegram), “Quick summary” (no AI), “Latest report” (`reports/latest.html`), “Cleanup: check” (`cleanup.py --dry-run`, output in a window), “Cleanup: run” (`cleanup.py --now`, after a confirmation). Free disk space next to them, orange below 20 GB.

**Widget** “Claude limits” (right-click the desktop → “Edit Widgets…” → AI Hub Bar): small — session % ring with the reset countdown; medium — session and week bars. It reads `usage.json`, refreshed whenever AI Hub Bar updates the limits.

**Module options per profile:** in Settings → “Profiles” → “Panel” each profile chooses what it shows inside a module: “Mac Resources” — which metrics (“Metrics: 2 of 7”), “Quick Commands” — which buttons of the shared library, “Quick Toggles” — which toggles, “Keep Awake” — whether the 15 min / 1 h / 2 h timers show. Nothing chosen means everything, as before; the choices travel in `.claudepult` files (format 2, new keys are optional).

**Context fullness:** a session's row shows “context 85%” from 70 % (orange, red from 90 %), and at 90 % one notification per session: Claude will soon compact the history. Taken from the last main-thread assistant message in the session's journal (input + cache writes + cache reads); the window is 200 000 tokens, or 1 000 000 for “[1m]” models or once the context is past 200 000. Hooks don't report it.

**Night queue:** “Tonight” in a project's actions queues the next step (or, in “Custom task…”, your own task) as a background run at the night start hour (Settings → Claude Code → “Background tasks”, 01:00 by default). Queued runs show in the limits card with “Cancel”. The Mac stays awake while they run (the “while Claude works” rule of “Keep Awake”), and when the night's runs are all done one summary arrives: “Overnight: 3 tasks — ✅ 2, ❌ 1” with a line per run, also in Telegram when “Result to Telegram” is on.

**Widget and Control Center:** a second widget “Sessions and projects” (small and medium): how many Claude sessions wait for an answer (and which), how many run, which projects are red. On macOS 26+ a Control Center control “Keep Awake (AI Hub Bar)” switches the manual keep-awake hold (needs the “Keep Awake” module). The app writes `widget-status.json` every 10 s when something changed and reloads the widget; the sandboxed control can't write the app's files, so it posts a Darwin notification (`com.demishev.claudepult.keepawake.on/off`) that AI Hub Bar listens for.

**Search, hot key, Shortcuts:** the panel has a search field under the header (sessions, projects, quick commands, report commands; ↵ runs the first match, Esc clears). ⌃⌥C (Settings → General: ⌃⌥C, ⌃⌥Space, ⌥⌘K or off) opens the same search as a small window in the middle of the screen from any app; there a project opens in Terminal, a session comes to the front. A query typed on the wrong keyboard layout (Cyrillic «ыгкм» for “surv”) matches too. The Shortcuts app gets three actions: “Claude limits” (returns the text, e.g. for Siri), “AI Hub Bar quick command” (runs a quick command by name) and “AI Hub Bar search”.

**PR and CI alerts:** when the project list refreshes (every 5 minutes, on panel open), a pull request whose CI turned red (“❌ CI failed: Cantero #41”), turned green again, or that is no longer open gets a notification; a click opens the PR. Optionally also to Telegram (the `_daily-report` bot, send-only). Settings → “Modules” → “Projects”. No data this time (no `gh`, offline) is never taken for “closed”.

**Answering from Telegram:** the same permission requests can go to Telegram as a message with “✅ Allow” / “❌ Deny” buttons (Settings → Claude Code → “Answers from Telegram”). It needs a bot of its own — the `_daily-report` bot already reads its updates and two readers would take each other's — created with @BotFather; its token is kept in the Keychain (`ClaudePult API key` / `telegram-approvals`), the chat is the `_daily-report` one unless set. Only presses from that chat count; the buttons disappear once the request is answered anywhere.

**Week forecast:** under the limit rings, “the week runs out Sat 04:56 at this pace” (orange) or “the week lasts until it resets”, and small bars for each day of the current week window (today highlighted, hover for the day's share). The plan gives only the week's total; it is split over the days in the proportions of Claude Code's journals (the same weights as “Usage by project”), and the pace is the last 24 hours. One notification per week window when the pace says the week runs out before the reset.

**What Claude is doing now:** a working session's row shows its last tool call in words — “editing LimitsView.swift”, “running npm test”, “searching TODO” (the task moves to the hover hint). With no tool call for 10 minutes the time turns into an orange “quiet N min”. The hook keeps `last_tool`, `last_target`, `last_tool_at` from PostToolUse (written when the action changes, else once a minute; cleared on Stop).

**Answering Claude from AI Hub Bar:** when a Claude Code session asks for a permission (a command, a file edit), the notification and the session row in the panel get “Allow” / “Deny”. The hook writes `approvals/<id>.request.json` and waits up to 290 s for AI Hub Bar's answer; Claude's own dialog is on screen at the same time, so whichever answer comes first applies. The hook only waits while AI Hub Bar runs with the option on (Settings → Claude Code, on by default); hooks installed before need “Update hooks” once (the PermissionRequest timeout grows from 5 to 300 s). In auto mode Claude rarely asks.

**Panel layout** (design variant A, chosen by Oleh 2026-10-30): every block sits on its own rounded card; the header holds the current profile (a menu when several are enabled) and icons for refresh (⌘R), Settings (⌘,), Help and Quit (⌘Q); the limits are two rings (session and week, colour by level, when each resets); sessions and projects are one line each (a project's branch shows only when it isn't `main`/`master`, a session's actions appear on hover); quick toggles are labelled tiles that light up when on. The “Dark” / “Light” panel theme now really applies (it is set on the panel window).

**Hover hints:** every control shown only as an icon has a hover hint; hovering over the menu bar item shows a summary of everything drawn in it (session and week, waiting, running, queued, reset countdown, forecast, nearest date, low disk, processor, memory, ☕, profile).

**Profiles** (SPEC-profiles; were “Modes”) — AI Hub Bar works in profiles made of modules: “AI limits”, “Agent sessions”, “Upcoming”, “Projects”, “`_daily-report` reports” (docs/SPEC-profiles.md). A profile chooses which of its modules the panel shows and in what order (Settings → “Profiles” → “Panel”; “Upcoming”, “Projects”, “Reports” appear when the profile has the calendar on, a project source or `_daily-report`) and has its own menu bar (Settings → “Menu Bar” edits the current profile's). The current setup is the profile “Developer — Oleh”. With more than one profile enabled, a switcher appears at the top of the panel; Settings → “Profiles” lists them (enable, order, duplicate, export, import, delete). Optional modules are installed from Settings → “Modules” (“Install” also adds it to the current profile, “Remove” takes it out of every profile; a profile adds or drops it in “Panel”). The first one is **“Mac Resources”**: processor, memory and pressure, graphics, disk, network, battery and the five busiest processes — every 2 s while the panel is open and every 30 s otherwise, only while installed; alerts for processor above 90 % for 5 minutes, critical memory, low disk and battery below 15 %; “Processor” and “Memory” menu bar elements. CLI: `AIHubBar --resources`. The second is **“Keep Awake”**: a power assertion (`pmset -g assertions` shows “ClaudePult keep awake”; System Settings are not touched) while Claude works (a session or a background run — on by default), on power, with an external display or while chosen apps run; by hand the panel switch (“until switched off”) and 15 min / 1 h / 2 h timers; optionally the display too; ☕ in the menu bar. The “Developer” template ticks it in the assistant. **“Also with the lid closed”** (laptops only): a power assertion doesn't survive a closed lid, so AI Hub Bar runs `pmset -a disablesleep 1` while a rule holds and `0` afterwards, on quit, when the module is removed and on battery below 20 %; “Allow…” asks for the administrator password once (macOS's dialog) and installs `/etc/sudoers.d/claudepult`, checked by `visudo`, allowing only those two commands; “Remove…” removes it. Sleep turned off by another app is left alone. **“Quick Commands”**: a library of buttons — a script in the background (zsh in the home folder, the last output line as a notification), a script in Terminal, a Shortcuts shortcut, or opening a link / file / folder / app; optional “Ask before running”; edited in “Modules”. **“Quick Toggles”**: dark mode and desktop icons (showing their state), lock and turn off the display, eject disks, empty the Trash (after a confirmation); dark mode and the Trash ask for the Automation permission once. **“Clipboard History”**: the last copies (text and files; 20 / 50 / 100 / 200), search, pins, a click copies an entry back; copies marked as secret (`org.nspasteboard.ConcealedType` and similar) and anything copied in password managers or Keychain Access (list in “Modules”) are never recorded; kept in memory unless “Keep after restart” is on (`clipboard.json`, owner-only). **“Notes”**: Markdown files in one folder (`~/Documents/ClaudePult Notes` by default, changed in “Modules”), one tab each, saved a second after typing, deleted to the Trash, “Open in Editor”. Template **“Mac Utilities”**: a profile without projects with these four modules. Settings → “Modules” is the catalog: what each module does, which profiles show it and its settings that don't depend on a profile (limits thresholds and sign-in renewal, calendar reminders). Settings → General → “Export Settings…” saves everything to a `*.claudepult` file, format version 2 (profiles with modules and menu bars; no keys or tokens; home paths as `~`); version 1 files still import. Double-clicking such a file in Finder imports it (“Replace all settings” or “Add profiles”). Oleh's settings: `docs/modes/oleh-developer.claudepult`. CLI: `AIHubBar --modes` lists profiles with their modules.

## Install

People get a `.dmg` from GitHub Releases, signed with the self-signed “ClaudePult Release” certificate and updated through Sparkle. Releasing it is covered in [docs/RELEASE.md](RELEASE.md) (`scripts/release.sh <version> [--publish]`). The code is under the MIT license ([LICENSE](../LICENSE)). From source:

Requirements: macOS 14+ (developed on macOS 27, Apple Silicon), Xcode with Swift 6 (developed with 27.1), `brew install xcodegen`.

```bash
scripts/build-and-install.sh
```

Generates `ClaudePult.xcodeproj` from `project.yml`, builds Release, installs `~/Applications/ClaudePult.app` and relaunches it. `--test` runs the unit tests first, `--no-launch` only installs. Signed ad-hoc; no Apple Developer account needed.

First steps after installing:

1. “Settings…” → “Claude Code” → “Install hooks” (adds AI Hub Bar's hook to `~/.claude/settings.json`, backup saved next to it).
2. Optionally “Start at login”.
3. The first “Terminal” launch makes macOS ask to let AI Hub Bar control Terminal — allow it; notifications — allow them.
4. For the limits, macOS may ask whether `security` may read “Claude Code-credentials” — “Always Allow”.
5. Notifications must be allowed (System Settings → Notifications → AI Hub Bar); the panel warns while they are off, Settings → General → “Check” sends a test one.

Notifications are clickable: “Claude is waiting for an answer” → the session's Terminal tab; a finished background run → its PR (“Open PR”) or “Log”; a report → `latest.html`; cleanup → its output.

- **General** — start at login, projects folder, `_daily-report` folder, version, app log.

- **Menu Bar** — the menu bar builder (SPEC-modes §7): presets “Minimum” / “Limits” / “Everything” / “Custom”; elements in order, each on/off with its options (icon symbol or the mode's icon; session / week / model week as number, ring or bar, shown always or from N %; reset countdown “2:14” or “2 h 14 min”; forecast; waiting, running sessions, background runs, queued launches — only when > 0; free disk below N GB; current mode as icon or name); separator, small text, colour by level or mono; live preview with “Now” / “Everything example” and a warning when the item gets wider than 180 pt; under the preview the switched-on elements as chips in menu bar order — drag one onto another to move it there (the ˄ ˅ buttons in the list still work). CLI: `AIHubBar --menubar-preview <file.png> [minimum|limits|everything]` draws the item (dark and light) with sample data.
- **Modules** — the module catalog: description, which profiles show it, “Subscription limits” (thresholds, Telegram, “Renew the Claude Code sign-in automatically”) and “Reminders” of the calendar.
- **Claude Code** — path to `claude` (empty = auto-detect: Homebrew, `~/.local/bin`, npm/pnpm/yarn/bun/volta/cargo/asdf/mise folders, what the login shell finds, nvm and fnm, then the copy inside the Claude desktop app; `codex`, `gemini`, `agy`, `copilot` and `cursor-agent` are found the same way, without the desktop app step); session hooks (install / update / remove); background runs (time limit, results in Telegram). Where Claude runs is set per profile.
- **Profiles → folder projects** (SPEC-modes §3): a mode's source can be “folders” (every subfolder of the projects folder is a project) or “one folder”. Words are counted in the main file (`.md`, `.txt`, `.rtf`, `.docx`, `.fountain`), or the newest text file. In the panel: stage switching (writes `Stage:` into `project.md`), open the folder / main file / card, “Create project.md”, “New project”. CLI: `AIHubBar --folder-projects <folder>`.

The interface is in all of them (String Catalog `ClaudePult/Resources/Localizable.xcstrings`, Russian is the source). In every language the templates (`template-*.<lang>.json`), the prompts and wrappers for AI services, new cards and content plans are written in that language; every language's file names and field names are always read, and a card keeps the language it is written in. - **Assistant** (SPEC-modes §5): Settings → Profiles → “+” → “Assistant…” builds a profile step by step — template or “From scratch”, “What the panel shows” (modules: limits, sessions, projects, upcoming; without projects the project steps are skipped), folder (it looks inside and suggests “git repositories” or “folders”), stages, metrics, calendar and reminders, AI service, commands, where Claude runs and what it may do in the background, panel blocks, menu bar preset, name and icon — with a live preview of the panel and the menu bar on sample data. - **Commands of folder projects** (SPEC-modes §3, §11): each folder mode has command templates (Settings → Profiles → “Project commands”: title, task with `{project}` `{file}` `{format}` `{platform}` `{duration}` `{text}` `{language}` (the Russian names work too), result file name with `<time>` / `<file>`, input “Main file” or “Whole project”, an optional question asked before running, a service of its own) plus “Custom task” always. In an expanded project they run with the chosen service: **models by API** get the main file's text and AI Hub Bar writes the answer to a new file; **Claude Code** runs in the background with the mode's permissions — “Project files only” (read and write inside the folder, no shell, no internet), “Files + web search” or “Code” — or in Terminal when the mode says so; **other agents** open in Terminal in the folder with the task on the clipboard. A result never overwrites a file (`-2`, `-3` …). **“Compare”** runs one command with 2–3 services → `hooks (Claude).md`, `hooks (OpenAI).md` …, shown side by side in the “Comparison” window. - **AI Services** (SPEC-modes §11) — agents found on this Mac with their version (Claude Code, OpenAI Codex CLI, Google Gemini CLI, Google Antigravity CLI, GitHub Copilot CLI, Cursor CLI; install command to copy when missing) and models by API (Anthropic, OpenAI, Google Gemini, xAI Grok, DeepSeek, Mistral, any OpenAI-compatible server such as Ollama / LM Studio / OpenRouter). An API key is stored only in the macOS Keychain (item “ClaudePult API key”, written through `/usr/bin/security`, never logged or exported); “Check” lists the provider's models (no tokens spent) and picks the model. Each mode has “Default service” (used by command templates from stage 4). Installed agents other than Claude appear in a project's “Open in…” menu (opens the agent in Terminal in the project folder). CLI: `AIHubBar --services [check]`.

## Background mode

`claude -p "<prompt>" --session-id <run id> --output-format stream-json --verbose --permission-mode dontAsk --permission-prompts none --settings '<rules>'` in the project folder or a new worktree. Anything not allowed is denied without asking:

- allowed: reading files, editing/writing inside the working folder, project checks and builds (npm, pnpm, npx, yarn, bun, node, tsc, mvn, gradle, xcodebuild, xcodegen, xcrun, swift, expo, pytest, make, `scripts/*`), `git status/diff/log/show/branch/add/commit/mv/rm/checkout -b/switch/fetch`, `git push origin <branch>` / `-u origin <branch>`, `gh pr create/view/list/checks/status`;
- denied: push to main/master or HEAD, bare `git push`, force/delete/mirror pushes, `git reset --hard`, `git clean`, deleting branches, `gh pr merge`, `gh api`, `sudo`, `rm`, reading `.env`, keys, `~/.ssh`, `_daily-report/config.json`, printing the environment.

Full rule set: `AIHubBar --background-settings`. Log: `~/Library/Application Support/ClaudePult/runs/<id>.log`, shown readably by “Log”. Time limit from Settings, then SIGTERM. On finish: a notification and, if enabled and `_daily-report/config.json` has the bot, a Telegram message “✅/❌ <Project>: <start of the task> — <result>” with the PR link. A run keeps going if AI Hub Bar quits. Runs older than 30 days are deleted. Note: Bash rules are pattern matching, not a sandbox — see DECISIONS.md.

## Session hooks

The hook (`~/Library/Application Support/ClaudePult/hooks/claudepult-hook.py`) listens to `SessionStart`, `UserPromptSubmit`, `PermissionRequest`, `Notification`, `PostToolUse`, `Stop`, `StopFailure`, `SessionEnd` and writes one file per session to `~/Library/Application Support/ClaudePult/sessions/<session_id>.json` (state, cwd, project, first/last prompt up to 200 characters, Claude's pid and tty). It prints nothing and always exits 0, so it never changes what Claude does. “Remove hooks” removes only AI Hub Bar's entries. Session files older than 7 days are deleted.

## Command line

The app binary runs headless commands instead of the UI: `~/Applications/AI\\ Hub\\ Bar.app/Contents/MacOS/AIHubBar <command>`.

| Command | Effect |
|---|---|
| `--login-item status\|on\|off` | start at login |
| `--claude next\|finish <project>` · `--claude task <project> <text>` | Claude command in a new Terminal window (worktree if busy); `finish` exits 3 if the folder is busy |
| `--claude … --background` | as a background run; the running app reports the result |
| `--claude … --print` · `--claude-path <path>` | print the command line · use another binary (e.g. `/bin/echo`) |
| `--background-settings` | permission rules of background runs |
| `--command report\|summary\|cleanup-check\|cleanup` | run a common command here and print its result |
| `--app-command <command>\|help\|cleanup-output\|settings` | ask the running app to run a command or open a window |
| `--hooks status\|install\|uninstall` | session hooks |
| `--modes` · `--export-settings <file>` | list modes (* = current) · export all settings (import: open the file) |
| `--notifications-status` · `--app-command test-notification` | notification permission · send a test notification |
| `--readiness [file.png]` | what this Mac still needs (AI service, hooks, notifications, start at login); exit 1 while something is left |
| `--usage` · `--usage-raw` · `--token-usage` | subscription limits (raw response; the token is never printed) · per-project breakdown |
| `--sessions` · `--show-session <id>` | list sessions · bring a session's Terminal tab forward |

```bash
xcodegen generate
xcodebuild test -project ClaudePult.xcodeproj -scheme AI Hub Bar -destination 'platform=macOS,arch=arm64'
```

`ClaudePult.xcodeproj` and `ClaudePult/Info.plist` are generated from `project.yml` and not committed. The app icon is generated by `swift scripts/make-app-icon.swift`.

Layout: `ClaudePult/App` (entry point, command line), `Models` (report, sessions, runs, commands, formatting), `Services` (processes, stores, hooks, launcher, Telegram, settings, log), `Views` (panel, rows, sessions, commands, windows, settings, help), `Resources` (icon), `ClaudePultTests` (Swift Testing).

Logs: `~/Library/Logs/ClaudePult/ClaudePult.log` (rotated at 1 MB). No tokens or file contents are logged.

Panel snapshots for checks (the app's windows are hidden from screen-capture automation): `defaults write com.demishev.claudepult DebugPanelSnapshot -bool YES` saves `panel.png`, `help.png`, `cleanup.png` to the log folder whenever those windows show; `defaults write com.demishev.claudepult DebugPanelExpand <project>` expands a project. Layout and text are reliable, some colours are not. Turn off with `defaults delete com.demishev.claudepult DebugPanelSnapshot`.
