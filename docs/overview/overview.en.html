At a glance

A control panel for working with AI

AI Hub Bar doesn't replace Claude, Codex or any other AI tool. It keeps an eye on them, starts them for you and shows the state of everything in one small panel under ✦ in the menu bar. It has no Dock icon and stays out of the way.

%

AI limits

Claude's 5-hour and weekly limits as rings, reset countdowns and a forecast. Codex, Copilot, Gemini CLI, Cursor, OpenRouter and API spend appear next to them.

✋

Agent sessions

Every Claude Code session on the Mac — Terminal, the Claude app, background runs — with what it is doing right now and how full its context is.

▶

Projects and commands

Your projects with their state. Expand one and run a command: next step, custom task, hooks for a video, proofreading, a source summary…

◐

Profiles

Developer, Video, Writing, Research, Marketing or your own. Each profile picks its modules, their order and its own menu bar.

▦

Calendar

Deadlines, publications and content plans from your project folders, with reminders. Drag an entry to another day and the file is updated.

⌘

Mac tools

Optional modules: Mac Resources, Keep Awake, Quick Commands, Quick Toggles, Clipboard History and Notes.

AI Hub Bar — Overview2
Limits

Know how much is left — and for how long

No more guessing whether the session will last until the evening. The limits sit right in the menu bar and in the first card of the panel.

Claude subscription

  • 5-hour session and week as rings, coloured by level: green below 50 %, orange to 80 %, red above.
  • Reset countdown and a forecast from the last 30 minutes: “enough until the reset” or “lasts until ~16:40”.
  • Week forecast with a small bar for each day: “the week runs out Sat 04:56 at this pace”.
  • Usage by project: each project's share and the heaviest session for the session, today and the week.
  • Per-model weekly limits and extra usage, when your plan has them.

Alerts that don't nag

  • One notification per window at 50 / 80 / 95 % (your choice) and when a limit is back.
  • Near the limit, background runs pause and carry on after the reset by themselves.
  • Later → After the limit resets queues a project's next step for the moment the session renews.
  • Each kind of notification can be limited or turned off.

Other AI services

Under Claude's rings, other services show up by themselves once they are found on the Mac or their key is saved: Codex limits, GitHub Copilot premium requests, Gemini CLI quota, Cursor, OpenRouter credits, and OpenAI / Anthropic API spend. Commands run by API count their tokens, with a monthly budget and alerts at 80 % and 100 %.

AI Hub Bar — Overview3
Claude Code sessions

Every agent on your Mac, in one list

Run Claude in five terminals, the Claude app and the background — AI Hub Bar shows them all and tells you the moment one of them needs you.

See what each session is doing

  • Project, worktree, task, duration and state: working, in background, waiting for you, done, error.
  • The current action in words — “editing LimitsView.swift”, “running npm test”. Quiet for 10 minutes? The row turns orange.
  • What changed since the session started: files and +/− lines from git; click for the file list.
  • Context fullness from 70 %, and one heads-up at 90 % before Claude compacts the history.
  • Show brings the right Terminal tab or Claude app window to the front.

Answer without switching windows

  • When Claude asks for permission, the notification and the session row get Allow / Deny.
  • Away from the Mac? The same request comes to Telegram with buttons. Whichever answer comes first applies.

Background runs you can trust

  • If Claude is already busy in a folder, a new task gets its own git worktree.
  • Background runs follow an explicit permission list: no push to main, no force push, no deleting, no reading secrets.
  • At night queues the next step for the night; in the morning, one summary of how it went.
  • Journal, Stop, a time limit, and a Telegram message with the PR link when a run finishes.

Profiles, projects and commands

Not only for developers

A profile is a set of modules for one kind of work. Start from a template, let the assistant ask a few questions, and change anything later.

TemplateA project isCommands, for example

Commands that never overwrite

  • A result is always a new file in the project folder.
  • Models by API get the project's main file; AI Hub Bar writes the answer.
  • Claude Code runs with the profile's permissions: project files only, files + web search, or full code.
  • Other agents open in Terminal with the task on the clipboard.

Compare and organise

  • Compare runs one command with two or three services and shows the answers side by side.
  • Stages (idea → script → editing → done) and metrics per project.
  • A small project card in each folder with Stage, Deadline and Main file — readable and editable by hand.
  • Several profiles at once, switched at the top of the panel; share one as a .claudepult file.

Extras for developers

  • Each repository's health, branch, uncommitted files and open PRs coloured by CI.
  • A notification when a PR's CI turns red or green again — a click opens the PR.
  • The project's STATUS.md header (Stage / Now / Next) right in the expanded row.
  • Worktrees listed per project, with a safe delete once they are clean and merged.
  • Open the project in Terminal, Finder, GitHub or another installed agent.
  • Finish asks Claude to run the checks, commit, push and open a PR.

AI Hub Bar — Overview6
Everywhere on the Mac

Reach it from anywhere

The panel is the centre, but AI Hub Bar also lives in the menu bar, on the desktop, in Control Center, in Shortcuts and in Telegram.

Menu bar, your way

Presets or your own set: limits as a number, ring or bar, the reset countdown, sessions waiting for you, the next deadline, processor, memory, free disk. Drag to reorder, with a live preview. Hover for a summary of everything.

⌃⌥C search

From any app: find a session, project, command or saved prompt and press ↵. A query typed on the wrong keyboard layout still matches.

Widgets and Control Center

“Claude limits” and “Sessions and projects” widgets for the desktop and Notification Center; a Keep Awake control on macOS 26+.

Shortcuts and Siri

Actions for Claude limits, a quick command by name and the search — combine them in your own automations.

Claude Code window

Every CLAUDE.md and AGENTS.md with search and editing, and MCP servers with an on/off switch. Saved prompts fill in {project}, {branch} and {file}.

Telegram and weekly summary

Finished runs, limit alerts, PR and CI changes and permission requests in Telegram. On Sundays, a summary of the week by project.

Private by design

  • No server, no account, no tracking. AI Hub Bar talks only to the AI services you use.
  • Your files go only to the service you run a command with.
  • API keys live in the macOS Keychain — never in logs or exported settings.
  • Claude's sign-in is read from the Keychain on each refresh and never stored.
  • Gemini and Cursor sign-ins are read only after you allow it, one by one.
  • Open source under the MIT license — read every line on GitHub.

Get started

Up and running in five minutes

You need a Mac with macOS 14 or later and at least one AI service: Claude Code with a subscription, another agent, or an API key.

Install

  1. Download the .dmg from GitHub Releases.
  2. Open it and drag AI Hub Bar to Applications.
  3. Open the app. macOS says it can't check the developer — close the message.
  4. System Settings → Privacy & Security → Open Anyway. Only once: after that the app updates itself.

First start

  1. The welcome screen checks what the Mac still needs: an AI service, the session hook, notifications, open at login.
  2. Import a .claudepult file — or pick a template.
  3. Tick what the panel shows and point to the folder with your projects.
  4. Skip anything: every choice can be changed later in Settings → Profiles.

Speaks your language

The interface and everything AI Hub Bar writes — templates, prompts, project cards, content plans — in 13 languages. It follows the system language, or pick one in Settings → General.

Updates

The app checks for new versions daily and installs them in one click. Settings → General → Updates.

Clean uninstall

Remove the session hook in Settings → Claude Code, quit, then delete the app and its data folder — the guide lists every path.

Build it yourself

Xcode and XcodeGen, then scripts/build-and-install.sh in the repository folder.
