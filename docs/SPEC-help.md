# Справка — техзадание

Согласовано с Олегом 2026-11-03: «нормальная современная Справка с анимацией и картинками», окно в приложении **и**
страница на сайте.

## 1. Окно «Справка» в приложении

- Открывается как прежде (кнопка «?» в панели, `--app-command help`), окно `help`, растягивается.
- Слева темы по разделам: Основы, AI, Работа, Mac, Ещё; поиск по названиям, описаниям, шагам и фактам — первая
  подходящая тема открывается сразу, найденные карточки подсвечены. Внизу — «Предложить идею…», «Сообщить о проблеме…».
- Страница темы: крупный значок и описание, кнопка «Открыть в настройках» (ведёт на нужную страницу настроек),
  анимированная картинка, «Как начать» (шаги), «Что умеет» (карточки со значками). У «Начала» — «Готовность».
- Код: `ClaudePult/Views/Help/` — `HelpTopics.swift` (содержание), `HelpIllustrations.swift` (картинки),
  `HelpView.swift` (окно).

## 2. Тексты

- Тексты старой справки, которые остались верны, взяты дословно — их переводы сохранились. Новое — про модули, места
  показа, разделители, остров, «Раскладку», уведомления.
- Все строки — через каталог, на 13 языках.

## 3. Картинки

- Нарисованы кодом, не скриншоты: не устаревают при смене оформления, работают на всех языках и в тёмной теме.
- Где можно — настоящие части приложения: строку меню рисует тот же `MenuBarRenderer`, значки модулей — `PaneIcon`.
- Короткие циклы по кадрам, кнопка «Показать ещё раз». С «Уменьшить движение» — последний кадр, без движения.

## 4. Сайт

- `site/help.html`: те же темы и тексты на 13 языках (выбор языка, по умолчанию — язык браузера), картинки — CSS-анимации
  по тем же сюжетам, с `prefers-reduced-motion` — без движения. Ссылка «Help» в шапке `site/index.html`.
- Данные — `site/help/<язык>.json`, их выгружает само приложение: `AIHubBar --help-export <файл>`
  (`-AppleLanguages "(en)"` — другой язык). Все языки разом: `scripts/export-help.sh`. После правки текстов справки —
  выгрузить и закоммитить.
