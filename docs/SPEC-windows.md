# ClaudePult для Windows — техзадание

Только спецификация: реализацию не начинаем, пока Олег не скажет (2026-10-30). Что делает ClaudePult, описано в `docs/SPEC.md`, `docs/SPEC-modes.md` и `docs/SPEC-profiles.md`. Здесь — как то же самое сделать на Windows, что получится хуже, чем на Mac, и в каком порядке это делать. Linux — в `docs/SPEC-linux.md`; у двух версий общая технология (§2) и общие этапы (§9).

Пункты с пометкой **(предложено)** Олег ещё не подтверждал. Пункты с пометкой **(проверить)** — факты о Windows и Claude Code, которые надо подтвердить на настоящей машине на этапе 0, прежде чем на них опираться.

---

## 1. Цель и границы

- Windows 11 и Windows 10 22H2, x64 и ARM64. Без прав администратора: установка, работа и обновления — только для текущего пользователя.
- Возможности — как у Mac-версии на момент начала работ: профили и модули (SPEC-profiles), лимиты, сессии, проекты, календарь, сервисы AI, фоновые задачи, 13 языков.
- Claude Code — родная установка для Windows (с Git for Windows). Claude Code внутри WSL — отдельный этап (§9, этап 8).
- Mac-версия остаётся на Swift и не меняется ради Windows. Общего кода с ней нет: общие только форматы файлов (§6) и тексты.

## 2. Технология (предложено)

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Tauri 2** (ядро на Rust, интерфейс на HTML/TypeScript) | одна кодовая база для Windows и Linux; маленький установщик; готовые модули: значок в трее, уведомления, автозапуск, один экземпляр, открытие файлов, обновления | интерфейс веб, а не родной WinUI; нужен WebView2 (в Windows 11 есть, для Windows 10 ставит установщик) |
| .NET + WinUI 3 | самый родной вид Windows 11 | только Windows: Linux пришлось бы писать отдельно |
| .NET + Avalonia | C#, Windows и Linux | трей и уведомления на Linux слабее, больше своего кода для системных мест |

**Предложение — Tauri 2.** Раз нужны и Windows, и Linux, одна кодовая база для обеих экономит примерно половину работы. Системные части (процессы, файлы, hooks, ключи, «Не спать») пишутся на Rust по одной на систему, остальное общее.

- Репозиторий: тот же `ClaudePult`, папка `desktop/` **(предложено)**. Mac-сборка (`project.yml`, Xcode) её не видит.
- Тексты: `ClaudePult/Resources/Localizable.xcstrings` переводится скриптом в JSON по языкам. Русский остаётся исходным, новые строки добавляются в `.xcstrings`, чтобы Mac и Windows не расходились. Для арабского — `dir="rtl"`.
- Шаблоны профилей (`ClaudePult/Resources/Templates/template-*.json`) и таблица языков содержимого (`ContentLanguage.swift`: имена файлов карточек и планов, поля, промпты) переносятся как данные, без изменения смысла.

## 3. Соответствие Mac → Windows

| На Mac | На Windows |
|---|---|
| Значок и текст в строке меню (`NSStatusItem`) | Значок в области уведомлений (трее). Текст рядом не помещается, поэтому значок рисуется на лету (§4.1) |
| Панель под значком (`NSPopover`) | Окно без рамки у значка: учитывается, с какой стороны панель задач; закрывается при потере фокуса |
| Настройки, «Календарь», «Сравнение», «Журнал», «Помощь» | Обычные окна, тот же состав вкладок |
| Токен лимитов из Связки ключей «Claude Code-credentials» | Файл `%USERPROFILE%\.claude\.credentials.json`, тот же JSON `claudeAiOauth` **(проверить)**. Читается при каждом запросе, не сохраняется и не пишется в журнал. Запрос тот же: `https://api.anthropic.com/api/oauth/usage` |
| `~/Library/Application Support/ClaudePult/` | `%LOCALAPPDATA%\ClaudePult\` (§6) |
| Hook на Python | Маленькая консольная программа `claudepult-hook.exe` из установки (§4.3): Python на Windows может не быть |
| Терминал через AppleScript | Windows Terminal (`wt.exe`), иначе окно PowerShell (§4.4) |
| «Показать» по tty | Хуже: окно, но не вкладка (§4.5) |
| `claude -p` в фоне, SIGTERM | То же `claude -p`, остановка через Ctrl+Break и Job Object (§4.6) |
| Уведомления (`UserNotifications`) | Всплывающие уведомления Windows (toast) с кнопками «Открыть PR», «Журнал» |
| Ключи API в Связке ключей | Диспетчер учётных данных Windows (`CredWrite`, цель «ClaudePult API key/<провайдер>»), шифрование DPAPI под пользователем |
| Вход в систему (`SMAppService`) | `HKCU\…\CurrentVersion\Run`. Учитывается выключение в «Параметры → Приложения → Автозагрузка» (`StartupApproved`) |
| Двойной клик по `.claudepult` | Регистрация расширения в `HKCU\Software\Classes` установщиком; файл передаётся уже запущенному экземпляру |
| Виджет WidgetKit | Не в первой версии (§4.9) |
| `ClaudePult --usage` и другие команды | Отдельная консольная программа `claudepult.exe` (§4.8) |
| `brew install …` в «Сервисах AI» | `winget install …` или `npm i -g …` |
| Свободное место на диске | Системный диск и диск папки проектов |
| Тема, размер текста, плотность | То же; «как в системе» — по `AppsUseLightTheme` в реестре |

## 4. Подробности

### 4.1 Значок в трее
- Windows показывает только квадратную иконку 16–32 px, поэтому вместо строки меню будет **рисованная иконка**:
  - кольцо или число процентов сессии, цвет по уровню (зелёный < 50 %, оранжевый 50–80 %, красный > 80 %);
  - точка в углу — есть сессии, ждущие ответа, или красный проект.
- Подсказка при наведении показывает полную строку, как в Mac-строке меню: «Сессия 42 % · сброс 2:14 · неделя 31 % · ✋ 1».
- Вкладка «Строка меню» становится «Значок в трее»: что рисовать в иконке (кольцо сессии, число сессии, кольцо недели, только ✦), что показывать в подсказке, цвета. Предпросмотр — как сейчас.
- Windows 11 по умолчанию прячет новые значки в «^». При первом запуске помощник показывает, как закрепить значок: «Параметры → Персонализация → Панель задач → Другие значки на панели задач».
- Не делаем своё окошко поверх панели задач: Windows так не задумана, и после обновлений такие окошки ломаются.

### 4.2 Лимиты и расход
- Как на Mac (SPEC §2, «Лимиты AI» в SPEC-profiles): сессия, неделя, недели по моделям, прогноз, уведомления на 50/80/95 %, Telegram.
- `usage.json` пишется в `%LOCALAPPDATA%\ClaudePult\usage.json` в том же формате (`five_hour`, `seven_day`, `updated`).
- «Расход по проектам» — из `%USERPROFILE%\.claude\projects\**\*.jsonl`, тот же разбор.
- «Продлевать вход Claude Code сам» — тем же способом, что на Mac, если Claude Code на Windows продлевает токен так же **(проверить)**.

### 4.3 Hooks и сессии
- Hooks записываются в `%USERPROFILE%\.claude\settings.json`, с резервной копией рядом, как на Mac. Команда hook — полный путь к `claudepult-hook.exe` в кавычках.
- `claudepult-hook.exe` слушает те же события (`SessionStart`, `UserPromptSubmit`, `PermissionRequest`, `Notification`, `PostToolUse`, `Stop`, `StopFailure`, `SessionEnd`) и пишет такой же файл сессии в `%LOCALAPPDATA%\ClaudePult\sessions\<session_id>.json`. Ничего не печатает, всегда выходит с кодом 0, работает меньше 100 мс.
- Вместо tty в файл сессии пишется то, по чему потом можно найти окно:
  - PID процесса Claude — поиск вверх по родителям через снимок процессов;
  - PID и окно терминала-хозяина;
  - `WT_SESSION` — идентификатор вкладки Windows Terminal из окружения.
- Сессии приложения Claude для компьютера: папка `%APPDATA%\Claude\claude-code-sessions` и ссылка `claude://code/continue?session=…` **(проверить, что приложение на Windows их использует)**.

### 4.4 Запуск Claude в терминале
- Настройка «Терминал»: Windows Terminal (по умолчанию, если установлен), PowerShell в отдельном окне, Git Bash.
- Windows Terminal: `wt.exe -w new new-tab -d "<папка>" --title "<проект>" pwsh -NoExit -File "<скрипт>"`.
  - Задача не передаётся в командной строке: `wt` делит команды по `;`, а кавычки в PowerShell и cmd экранируются по-разному.
  - Поэтому ClaudePult пишет задачу во временный файл, а маленький скрипт запускает `claude` с текстом из файла и удаляет файл.
- Worktree — как на Mac (`.claude/worktrees/cb-<slug>`, ветка `claude/<slug>`). Перед первым worktree ClaudePult предлагает `git config --global core.longpaths true`: пути в `.claude\worktrees\…` легко превышают 260 символов.
- «Открыть в…» для других агентов — так же, через Windows Terminal в папке проекта.

### 4.5 «Показать»
Хуже, чем на Mac, и в интерфейсе это прямо сказано.
- У Windows Terminal нет команды «перейди на вкладку с такой-то сессией»: `focus-tab` знает только номер вкладки.
- Окна, которые открыл сам ClaudePult, получают имя `cp-<id>`. «Показать» вызывает `wt.exe -w cp-<id> focus-tab -t 0`: окно с одной вкладкой выходит вперёд **(проверить)**.
- Сессии, начатые не из ClaudePult: окно терминала находится по родителям процесса Claude и выводится вперёд (`SetForegroundWindow` после клика пользователя разрешён). Вкладку при этом выбирает сам человек.
- Сессии приложения Claude — по ссылке `claude://`, как на Mac.

### 4.6 Фоновые задачи
- Та же команда `claude -p … --permission-mode dontAsk --permission-prompts none --settings '<правила>'`, журнал в `%LOCALAPPDATA%\ClaudePult\runs\<id>.log`, то же чтение в «Журнале».
- Процесс запускается в своей группе (`CREATE_NEW_PROCESS_GROUP`) и в Job Object без `KILL_ON_JOB_CLOSE`. Так задача переживает выход из ClaudePult, как на Mac.
- Остановка: сначала Ctrl+Break группе, чтобы Claude успел выполнить `SessionEnd` **(проверить)**; через 10 с — `TerminateJobObject`.
- Правила разрешений — те же, плюс запреты для Windows:
  - `del`, `rd`, `rmdir`, `Remove-Item`, `format`, `reg`, `Set-ExecutionPolicy`, `runas`;
  - чтение `%USERPROFILE%\.ssh`, `.env` и ключей.
- Список разрешённых сборщиков — тот же, плюс `dotnet`, `msbuild`, `cargo`, `powershell`/`pwsh` только для `scripts\*.ps1` проекта.
- В DECISIONS.md остаётся оговорка: правила — сравнение по шаблону, а не песочница.

### 4.7 Проекты, команды, календарь
- Сканер git, папочные проекты, `проект.md`, этапы, метрики, календарь, команды проектов, «Сравнить» — та же логика.
- Файлы читаются с любыми концами строк (CRLF и LF), а пишутся в UTF-8 без BOM и с концами строк того файла, который уже есть.
- Папка проектов по умолчанию — `%USERPROFILE%\Projects`.
- `git` и `gh` берутся из PATH. Если `gh` нет, помощник предлагает `winget install GitHub.cli`.
- Модуль «Отчёты `_daily-report`»:
  - работает, если папка найдена и есть `python`;
  - «Очистка» скрыта: `cleanup.py` чистит то, что бывает только на Mac (Xcode, симуляторы).

### 4.8 Командная строка
- Главная программа `ClaudePult.exe` — оконная, в консоль она печатать не может. Поэтому рядом ставится `claudepult.exe` (консольная) с теми же командами, что на Mac: `--usage`, `--sessions`, `--hooks`, `--readiness`, `--modes`, `--app-command` и т. д.
- Связь с запущенным приложением (`--app-command`, второй запуск, открытый `.claudepult`) — именованный канал `\\.\pipe\ClaudePult-<пользователь>`.
- Установщик добавляет папку программы в PATH пользователя **(предложено)**.

### 4.9 Виджет
- Доска виджетов Windows 11 работает только у приложения, упакованного в MSIX, с COM-поставщиком виджетов.
- **(предложено)** Не в первой версии: подсказка у значка и так показывает лимиты. Вернуться, если будет MSIX (§7).

### 4.10 Модули из SPEC-profiles

- **«Ресурсы Mac» → «Ресурсы компьютера» (предложено)**:
  - процессор и память — `GetSystemTimes`, `GlobalMemoryStatusEx`;
  - процессы — счётчики PDH;
  - диск — `GetDiskFreeSpaceEx`;
  - сеть — `GetIfTable2`;
  - батарея — `GetSystemPowerStatus`;
  - графика — счётчики «GPU Engine».

  Клик по «прожорливым» открывает Диспетчер задач. Уведомления — те же.
- **«Не спать»**:
  - `PowerCreateRequest` / `PowerSetRequest` (система, по выбору и экран). Системные настройки не меняются.
  - Правила те же: вручную, от сети, внешний монитор (`EnumDisplayMonitors`), «пока работает Claude», пока запущены выбранные приложения.
  - «С закрытой крышкой» требует менять схему питания (`powercfg`), поэтому это вторая волна, как на Mac.
- **«Быстрые команды»**:
  - скрипт — PowerShell или cmd;
  - «открыть» — ссылка, файл, папка, приложение;
  - ярлыков «Команд» macOS на Windows нет, этот вид скрыт.
- **«Быстрые переключатели»**:
  - тёмная тема — реестр `AppsUseLightTheme` / `SystemUsesLightTheme` и рассылка `WM_SETTINGCHANGE`;
  - скрыть значки на рабочем столе — `HideIcons` и обновление Проводника;
  - заблокировать — `LockWorkStation`;
  - погасить экран — `SC_MONITORPOWER`;
  - очистить корзину — `SHEmptyRecycleBin`, с подтверждением;
  - «Извлечь диски» — вторая волна: безопасное извлечение (`CM_Request_Device_Eject`) требует отдельной проверки.

## 5. Сервисы AI
- Агенты ищутся в PATH (`where.exe`) и в обычных местах: `%APPDATA%\npm`, `%LOCALAPPDATA%\Programs`, папки winget. Команды установки — `winget` или `npm i -g`.
- Модели по API — без изменений. Ключи — в Диспетчере учётных данных (§3). Расход по API — `%LOCALAPPDATA%\ClaudePult\api-spend.json`.

## 6. Данные и файлы

| Что | Где |
|---|---|
| Настройки, профили, модули | `%LOCALAPPDATA%\ClaudePult\settings.json` |
| `usage.json`, `api-spend.json` | `%LOCALAPPDATA%\ClaudePult\` |
| Файлы сессий | `%LOCALAPPDATA%\ClaudePult\sessions\` |
| Журналы фоновых задач | `%LOCALAPPDATA%\ClaudePult\runs\` |
| Журнал приложения | `%LOCALAPPDATA%\ClaudePult\logs\` |

- `%LOCALAPPDATA%`, а не `%APPDATA%`: сессии и задачи принадлежат этому компьютеру, их не надо переносить с перемещаемым профилем.
- Файл `.claudepult` — тот же формат версии 2. Домашняя папка пишется как `~`, разделитель путей в файле — `/`. Так файл с Mac открывается на Windows и наоборот.
- Модули и команды, которых на этой системе нет (ярлык «Команд», виджет), сохраняются в файле. В профиле они показываются как «недоступно на Windows».

## 7. Установка, подпись, обновления
- Установщик для текущего пользователя (NSIS или MSI) в `%LOCALAPPDATA%\Programs\ClaudePult`. Он кладёт ярлык в меню «Пуск» (без ярлыка не работают уведомления), регистрирует `.claudepult` и `claudepult://` и добавляет `claudepult.exe` в PATH.
- **Подпись.** Без подписи SmartScreen показывает «Windows защитила ваш компьютер», и новичок дальше не пойдёт. Варианты:
  - Azure Trusted Signing — подписка, нужна проверка личности или компании;
  - сертификат OV или EV у центра сертификации — дороже, на год.

  Решает Олег, вместе с решением про Developer ID на Mac (SPEC-modes §10.4).
- **Обновления**: встроенный в Tauri механизм, подписанный манифест на GitHub Releases. Позже — пакет в `winget`.
- MSIX и Microsoft Store — не сейчас. Понадобятся только ради виджета (§4.9).

## 8. Чего не делать
- Не просить прав администратора и не ставить службы.
- Не менять системные настройки без клика человека (как SPEC-profiles §4.4).
- Не трогать Mac-версию ради Windows; если общий формат файла меняется, то меняется в обеих версиях сразу.
- Без телеметрии. Не копировать код GPL-проектов.
- Не обещать в интерфейсе того, что на Windows не работает: «Показать» без вкладки так и называется.

## 9. Этапы

Общие с Linux: на Tauri каждый этап делается для обеих систем сразу (SPEC-linux §9). Каждый этап — ветка, проверки, установка в виртуальную машину, проверка вживую, STATUS, PR.

0. **Проверка фактов** на Windows 11 ARM в виртуальной машине на Mac (UTM бесплатно или Parallels). Проверить все пункты с пометкой «проверить»:
   - где Claude Code хранит токен;
   - `claude://` и папка сессий приложения Claude;
   - `wt -w <имя> focus-tab`;
   - Ctrl+Break и `SessionEnd`;
   - как запускаются hooks.

   Итог — исправления в этом документе.
1. **Каркас**: значок в трее, панель, окно настроек, 13 языков, один экземпляр, автозапуск, `claudepult.exe`, канал связи.
2. **Лимиты**: токен, запрос, прогноз, уведомления, Telegram, `usage.json`, расход по проектам.
3. **Сессии**: `claudepult-hook.exe`, установка и снятие hooks, список сессий, «Показать».
4. **Проекты и Claude**: сканер git, STATUS.md, запуск в терминале и в фоне, worktree, журнал, правила разрешений.
5. **Профили и модули**: `.claudepult`, помощник, шаблоны, папочные проекты, календарь, сервисы AI, команды проектов, «Сравнить».
6. **Новые модули**: Ресурсы, Не спать, Быстрые команды и переключатели.
7. **Распространение**: установщик, подпись, обновления.
8. **WSL** (если нужно): hooks и токен из Linux-части, запуск Claude через `wsl.exe -d <дистрибутив> --cd <папка>`.

Проверка: CI нет (Actions платные), поэтому ядро на Rust тестируется на Mac, а сборка и интерфейс — в виртуальной машине. В STATUS → Checked пишется, что именно прогнано.

## 10. Открытые вопросы
- Tauri 2 и одна кодовая база для Windows и Linux — подтвердить, или WinUI только для Windows.
- Папка `desktop/` в этом же репозитории или отдельный репозиторий.
- Подпись: Azure Trusted Signing или сертификат; кто владелец (частное лицо или компания).
- Нужен ли Claude Code внутри WSL (этап 8) и насколько рано.
- Минимальная версия: оставить Windows 10 22H2 или только Windows 11.
- Название «Ресурсы компьютера» вместо «Ресурсы Mac» на Windows и Linux.
