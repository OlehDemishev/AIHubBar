# «Быстрый запрос» — задача агенту из любого приложения

Выбрано Олегом 2026-11-03 среди четырёх новых возможностей. Необязательный модуль раздела AI (Настройки → Модули →
«Быстрый запрос»). Код: `AIHubBar/Models/QuickPrompt.swift` (решения, чистые, с тестами),
`AIHubBar/Services/QuickPromptController.swift` (клавиша, что впереди, отправка), `AIHubBar/Modules/QuickPromptModule.swift`
(модуль и его настройки), `AIHubBar/Views/Windows/QuickPromptWindow.swift` (окно).

## 1. Что умеет

- Горячая клавиша в любом приложении (по умолчанию **⌃⌥P**) открывает маленькое окно посреди экрана, поверх других окон.
- В окне: поле задачи, проект, агент и куда отправить — **«В фоне»** или **«В Терминале»**.
- **⌘↩** — отправить, **Esc** — закрыть. Окно закрывается само, когда задача ушла.
- Ещё открывается командой `AIHubBar --app-command quick-prompt` (для скриптов и «Команд» macOS).

## 2. Проект

- Список — git-проекты текущего профиля (те же, что в «Проектах»). У профиля с папками-проектами (тексты, видео) git-проектов
  нет: окно говорит, где их указать.
- По умолчанию выбран, по порядку:
  1. **проект того, что впереди**, если это видно: документ переднего окна лежит в папке проекта (Xcode, редакторы) или в
     заголовке окна есть имя проекта (Терминал, VS Code — «ClaudePult — zsh»). Читается через «Универсальный доступ», только
     если он уже выдан (его просит «Раскладка»); сам модуль доступа не просит;
  2. проект прошлого запроса;
  3. проект с самой свежей активностью.

## 3. Агент и куда

- **Claude Code** — по умолчанию, при каждом открытии. Дальше — другие установленные агенты (`AgentLocator`, «Сервисы AI»).
- Claude Code: «В фоне» — фоновая задача (`claude -p`, права, лимит времени, итог уведомлением), «В Терминале» — новое окно
  Терминала. Это тот же запуск, что «Своя задача…» у проекта: та же подсказка, worktree, если в папке уже работает Claude,
  вопрос при сессии выше 90 %. Вопросы («Запустить всё равно», «После сброса») показываются прямо в окне.
- Другие агенты — только «В Терминале», как «Открыть в…» и команды профиля: агент открывается в папке проекта, задача
  кладётся в буфер обмена, «вставьте ⌘V». Фон для них — когда их флаги прав проверены вживую (SPEC-modes §11).
- Куда отправлять — запоминается с прошлого запроса; в первый раз — как «Терминал / Фон» в Настройках, иначе «В фоне».

## 4. Настройки

- Страница модуля: **«Горячая клавиша»** — Выключено, ⌃⌥P, ⌃⌥A, ⌃⇧Пробел. Клавиша работает, только пока модуль включён.
- Других настроек нет: проект и «куда» запоминаются сами.

## 5. Чего не делать

- Не просить разрешений заранее: клавиша — Carbon hot key, ей ничего не нужно.
- Не отправлять задачу никуда, кроме выбранного агента; текст задачи не пишется в журнал приложения.
- Не занимать клавиши поиска (⌃⌥C, ⌃⌥Пробел, ⌥⌘K) и острова (⌃⌥Y / ⌃⌥N).
