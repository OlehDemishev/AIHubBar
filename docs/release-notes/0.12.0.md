## New

- **Codex approvals** — “Allow” and “Deny” for Codex's permission requests in the notification, the session row and Telegram, like Claude's. Update the Codex hook in Settings → AI Services → Codex, then trust it once in Codex's `/hooks`.
- **Codex in the background** — Quick Prompt sends a task to Codex without a window (`codex exec`): it writes only in the project folder, can commit, has no network, and the result comes as a notification, like Claude's. Near Codex's own limit such a task is paused until the reset, and a new one asks first.
- **Hand over to Codex** — when Claude is near its limit, the launch question offers “To Codex”, and a paused or failed background task has “Hand Over to Codex” in its menu: Codex continues in the same folder and is told to look at the work already there.
- **Review by the other service** — a finished background task has “Review in Codex” (or “Review in Claude” for Codex's work): the other service reads the changes, changes nothing and answers “OK” or a list of problems. Both this and the handover are also buttons under a task's log in Telegram.
- **One task, two services** — in Quick Prompt tick “Also in Codex — to compare”: Claude and Codex get the same task, each in its own worktree (Codex cannot commit in a worktree, so AI Hub Bar commits its changes when it finishes), and one notification says how both ended and how much each changed. “Compare with…” in either task's menu (or a click on that notification) opens the two answers side by side with the files each one changed; files both touched are marked.
- **Skills and plugins** — the Claude Code window has a third tab: the skills of Claude Code and Codex and Claude Code's plugins with a switch each, and the hooks of both to look at.
- **Day summary** — the Usage History window opens with “Today”: spend by project, background tasks with their outcome and every service's limits. The same can come to Telegram once a day (Settings → What to Show → AI limits; off by default).
- **Does the plan pay off** — Usage History compares the period's spend at your API price with what you pay for the plan a month, and “Today” shows the day's cost.
- **Telegram off in one click** — a “Telegram” tile in Quick Toggles turns Telegram notifications off until you press it again; permission requests and the bot's replies still come.
