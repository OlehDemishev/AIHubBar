## New

- **Versions** — a new module for people who write in folders: the texts and the project card of a folder project are saved before every AI run and, while something changes, every 10 minutes. Versions live in the app's folder, not in the project, and are sent nowhere. Settings → Modules → Versions sets how often and how long, and shows the space they take. New profiles made from the Texts, Video, Research and Social templates come with it switched on.
- **Versions in a project's card** — "Versions" in an expanded folder project opens the list of its versions by time, each with the reason it was taken. A file from a version is shown next to the same file now, line by line, `.docx` and `.rtf` included. "Restore This File" and "Restore the Whole Version" put it back; the current state is saved as a version first, and files that appeared later stay.
- **What Changed** — the notification about a finished command on a folder project and the run's Log get "What Changed": the project's texts before the task against now.
