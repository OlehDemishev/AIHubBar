## New

- **Versions** — a new module for people who write in folders: the texts and the project card of a folder project are saved before every AI run and, while something changes, every 10 minutes. Versions live in the app's folder, not in the project, and are sent nowhere. Settings → Modules → Versions sets how often and how long, and shows the space they take. New profiles made from the Texts, Video, Research and Social templates come with it switched on.
- **Versions in a project's card** — "Versions" in an expanded folder project opens the list of its versions by time, each with the reason it was taken. A file from a version is shown next to the same file now, line by line, `.docx` and `.rtf` included. "Restore This File" and "Restore the Whole Version" put it back; the current state is saved as a version first, and files that appeared later stay.
- **What Changed** — the notification about a finished command on a folder project and the run's Log get "What Changed": the project's texts before the task against now.
- **Batch tasks** — "Choose" under the list of folder projects: tick several projects, pick one of the profile's commands and when to run it — now, at night or after the limit resets. The projects go one after another in the background (Claude Code or a model by API), the batch waits near a limit, and one summary comes at the end. A command that asks for text asks once for the whole batch.
- **An agent may be stuck** — a notification when a session has been working for 20 minutes without doing anything, or keeps running the same command over and over. Its frequency is on the Agent Sessions page, like the other notifications.
- **Waiting for you** — the day summary (Usage History → Today, and the daily Telegram message) now starts with what is left for you: sessions waiting for an answer and pull requests whose checks failed.
- **Local servers** — an expanded project lists what listens on a port from its folder: the port, the program, a button to open it in the browser and one to stop it (it asks once more).
- **Files and dictation in Quick Prompt** — drag files or screenshots into the window and the agent gets their paths with the task; the microphone button starts macOS Dictation in the task field.
- **More Shortcuts actions** — “Keep Awake” (for an hour, until turned off, off), “Who Is Waiting” and “Claude Task in the Background” join the three actions that were there.
- **Swap** — Mac Resources tells you when swap has grown to half of the Mac's memory: memory has been short for a while and swap is eating disk space.
- **Antigravity waits** — a notification when Antigravity asks whether to run a command, not only the word in its row.
- **Calendar to .ics** — the Calendar window exports deadlines and publication dates to a file any calendar app opens.
- **A writing goal** — a profile for texts can have a daily word goal: the projects block shows “Words today: N of M” and the days in a row, and a notification comes once when the goal is reached.
- **Beta badges** — what was checked less than the rest now says so: the services other than Claude, the translations nobody has read yet, comparing and handing over between services, Versions and batch tasks.
