## New

- **Skills** — a new module: every skill and plugin of Claude Code, Codex, Cursor and Gemini CLI on this Mac in one list, each checked for safety without running anything. A verdict (safe, review, dangerous) comes with why: the findings that decided it, what the skill can do, what would make it safer. Switch it on in Settings → What to Show; a puzzle button in the panel's header opens the section, a block on the main panel shows alerts and the skills used this week.
- **Find and keep** — search by name, description and your notes; filters by risk, agent, place, what a skill can and can't do, license, author, usage; favourites, private notes and saved filters.
- **Install and undo** — install a checked skill for another agent from its card (the plan first; "review" and "dangerous" need a ticked box), switch it off and on, remove it into the catalog's backups, put anything back from the journal. A newer version of a copy the catalog made is checked first and shown line by line.
- **Complaints and a block list** — a complaint stays on your Mac; send it to the skill's author on GitHub or to AI Hub Bar only if you choose. A blocked skill can't be installed or updated, and an installed one is an alert.
- **Watching and policy** — a notification when a skill appears or changes outside the catalog, and for newer versions; a policy for what may be installed (all, all but dangerous, safe only, trusted authors only).
- **AI review** — on request, Claude reads a skill (through Claude Code with no tools, or the Anthropic API with your key) and explains what it would make an agent do. Its answer can only make the verdict stricter.
- **Order** — name conflicts between versions, the same skill copied into several folders, skills nobody used for 30 days, named sets, and an export of everything with file hashes to check against later.
