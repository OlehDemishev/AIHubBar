AI Hub Bar doesn't replace Claude, Codex or any other AI tool — it keeps an eye on them and starts them for you. Free, open source, no account and no server of its own.

Features

Three things, one click on ✦

◔

Limits — how much is left

  • Claude's 5-hour and weekly limits as rings, with a reset countdown, right in the menu bar.
  • A forecast from your pace: “enough until the reset” or “lasts until ~16:40”.
  • Usage by project, and notifications at the thresholds you choose.
  • Codex, GitHub Copilot, Gemini CLI, Cursor, OpenRouter and API spend appear by themselves.
≡

Every Claude Code session

  • Terminal, the Claude app, background runs: state, task, duration — and what Claude is doing right now.
  • Allow or Deny permission requests from the notification, the panel or Telegram.
  • Context fullness, files changed, and a heads-up when a session goes quiet.
  • Background runs under an explicit permission list, a night queue and a morning summary.
⌘

Projects and AI commands

  • Profiles built from modules, each with its own panel and menu bar.
  • A command's result is always a new file — nothing is overwritten.
  • Compare runs one command with two or three services side by side.
  • Claude Code, Codex CLI, Gemini CLI, Copilot CLI, Cursor CLI and models by API.

Install

Two minutes, once

  1. Download AIHubBar-<version>.dmg from Releases.
  2. Open it and drag AI Hub Bar to Applications.
  3. Open the app. macOS says it can't check the developer — close the message.
  4. System Settings → Privacy & Security → Open Anyway.

The app isn't signed with an Apple Developer ID, so macOS asks once. After that it updates itself, and the first start opens an assistant that sets up your first profile.

Needs: macOS 14 or later (Apple Silicon or Intel) and at least one AI service. Limits and the session list need Claude Code.

Privacy

Nothing in between

No server, no account, no analytics. AI Hub Bar talks only to the AI services you use, and your files go only to the service you run a command with.

Keys stay in the Keychain. Never in logs or exported settings. The session hook only writes small status files on your Mac and can be removed in Settings.
